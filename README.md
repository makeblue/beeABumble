# Bee A Bumble

A static website for **Bee A Bumble** – pure raw honey and natural bee products.

## Structure

| File | Description |
|------|-------------|
| `index.html` | Main single-page site (Home, Shop, About, Contact) |
| `styles.css` | Styles — golden/amber bee-themed design |
| `script.js` | Minimal JS — sticky nav, mobile menu, form validation |

## Deploying to GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Set the source to the `main` branch, root folder (`/`).
3. The site will be live at `https://makeblue.github.io/beeABumble/`.
